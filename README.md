# Assistant accessibilité réseaux sociaux

Page web qui vérifie une publication Instagram ou Facebook avant sa mise en ligne, point par point.

**Utilisation :** ouvrir la page, glisser une image, un carrousel ou une vidéo, coller la légende et les textes alternatifs. Chaque point de la fiche de contrôle s'affiche avec un verdict : conforme, à corriger, à vérifier à l'œil ou sans objet. Le rapport se copie ou se télécharge.

**Contrôles automatiques**

- Texte alternatif : présent, assez long, une description par slide pour un carrousel.
- Légende : première ligne courte (Instagram coupe vers 125 caractères), blocs de texte, polices « fantaisie », mention jeu responsable.
- Hashtags avec une majuscule à chaque mot, emojis répétés, liens « cliquez ici ».
- Vidéo : flashs (plus de 3 par seconde), rythme et longueur des sous-titres d'un fichier `.srt`, format 9:16.
- Contraste texte / fond mesuré à la pipette (minimum 4,5:1).

**Confidentialité :** tout se passe dans le navigateur. Aucun fichier n'est envoyé.

Un seul fichier, `index.html`, sans dépendance à installer.
